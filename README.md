# 연봉협상 시뮬레이터

## 여는 방법
`index.html`을 더블클릭해서 크롬이나 엣지로 엽니다. 설치할 것은 없습니다.

처음 받았거나 `data/seed.js`가 없다면, `data/seed.example.js`를 `data/seed.js`로 복사한 뒤 실제 인원으로 내용을 바꾸세요. `data/seed.js`는 `.gitignore`에 들어있어 깃에 올라가지 않습니다.

## 데이터 입력
- 직원: 「개인별 협상표」에서 수정, 「직원 추가」로 추가, 이름을 누르면 상세 정보·퇴사 처리
- 인상 이력: 「인상 이력」 탭에서 수정·추가·삭제
- 월별 매출·인건비: 「법인별 분석」 탭 (엑셀 한 줄 붙여넣기 가능)
- 법인·계산 기준: 「설정·데이터」 탭

입력값은 이 컴퓨터의 브라우저에 자동 저장됩니다. 다른 PC로 옮기거나 백업할 때는 상단 「시나리오 저장」 파일을 쓰세요.

## 주의
`data/seed.js`와 저장한 시나리오 파일에는 직원 실명과 연봉이 들어 있습니다. 사내에서만 보관하세요.

코드 구조와 계산 규칙은 `CLAUDE.md`에 정리되어 있습니다.
